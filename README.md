# 3000FinalProject
Abstract 

Deepfake manipulation increasingly poses a threat to information reliability, particularly on social media platforms, where users are frequently exposed to synthetic content.  This project presents Gaize, a deepfake detection app, which was developed to combat false narratives because of synthesised content and improve accessibility for users with limited technical expertise. This project was developed using agile methods and regular sprint reviews. This resulted in a functional app, with a trained deepfake model using the FaceForensic++ dataset. The final convolution neural network has temporal features extraction to analyse both spatial and motion-based inconsistencies in video data. Although a successful application was completed, there is room for improvement. The accuracy score of the final model was 66% indicating that the model missed out on a lot of temporal cues.
